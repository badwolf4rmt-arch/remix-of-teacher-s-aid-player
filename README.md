# Teacher's Aid Player

Из этого проекта забери в мой новый проект только фронт, не забирай функции генерации ИИ, так как бэк. хочу полностью перестроить. Внутри ты увидишь первый экран, который передает входные параметры - это оставь как есть. после параметров должен открыться плеер контента, в котором должно быть 2 области: задание и заметки для учителя. эти области должны отображать маркдаун и латех форматирование. но брать контекст полностью от ии (пока не встроено). также добавь на страницу , слева, область для ценивания, как на скрине. В вверху сделай поле "Пользователь" для заполнения, выбор модели (варианты Claude / Gemini), настройку промптов. промптов должно быть 3 шт., я тебе их передам позже. сейчас собираем только фронт!
