## Редизайн по референсам

Перестрою UI строго по трём скринам, сохранив всю текущую логику (параметры → плеер → оценка → Supabase, шапка с User/Model/Prompts).

### Визуальная система (по референсам)

- Фон приложения: сплошной серо-фиолетовый (`#6b6b7d`-подобный), карточки — белые с большим `border-radius` (~20px) и мягкой тенью.
- Акцент: индиго/фиолетовый (`#5b4fe6` / `#6c5ce7`) — активные кнопки, тогглы, чипы.
- Поля ввода и селекты: светло-лавандовый фон (`#eeecff`), без видимой рамки, скругление ~12px.
- Обязательные поля помечаются красной `*`.
- Типографика: sans-serif, крупные заголовки (24–28px, semi-bold), тёмный текст `#1a1a2e`.
- Кнопки: «primary» — залитая индиго, «secondary/cancel» — светло-лавандовая с тёмным текстом, «disabled» — та же лавандовая с приглушённым текстом.

Токены пропишу в `src/styles.css` (обновлю `--background`, `--primary`, `--muted`, `--input`, добавлю `--surface-lavender`), чтобы не хардкодить цвета в компонентах.

### Экран 1 — Параметры (`/`) по скрину 1

Форма превращается в модальное окно-карточку по центру серого фона:
- Заголовок «Мотивирующее задание» + иконка закрытия (визуальная, ведёт на `/`).
- Ряд: `Предмет*` + `Параллель*` (класс) — два селекта на светло-лавандовом фоне; выбранное значение показывается как «чип» с крестиком (как «6 ✕» на скрине).
- `Тема задания*` — инпут.
- Тоггл «Добавить иллюстрацию» (индиго switch) — новое поле, добавлю в `FormDraft` как `withIllustration: boolean` (default `true`).
- `Формат задания` — селект с плейсхолдером «Любой».
- `Важно учесть` — textarea с лимитом 300 символов и счётчиком `0/300` в правом нижнем углу; переименую текущее `additionalRequest`.
- Кнопки: `Отменить` (сброс формы) и `Сгенерировать` (индиго, disabled, пока не заполнены обязательные) — вместо текущей «Открыть плеер». По клику: сохранить параметры и перейти на `/player`.

Заменю `is_new_topic` (в референсе его нет) — удалю из формы; каталоги `SUBJECT_CATALOG` / `GRADE_CATALOG` оставлю как есть.

### Экран 2 — Плеер (`/player`) по скрину 2

Полностью переверстаю layout:

- Верхняя панель приложения (белая, тонкая): слева хлебные крошки «Главная / Мотивирующее задание», справа — иконки `...`, `save`, кнопка `Предпросмотр` (outline), кнопка `Выдать` (индиго).
  - В эту же панель встрою нашу существующую логику: поле «Пользователь», селект модели (Claude/Gemini), кнопка «Промпты» (открывает Sheet с 3 полями — Этап 1/2/3). Разложу их слева от иконок действий, чтобы не ломать референс.
- Вторая полоса — «тулбар форматирования» (декоративный, статичные иконки-заглушки: абзац, Ж/К/Ч, цвет, формула, список и т.д.). Чисто визуальный, без функционала — соответствует референсу.
- Основная область — две колонки:
  - Левая (шире, ~2fr): карточка с бейджами «Мотивирующее задание» / «Кейс» (из параметров), крупный заголовок темы, ниже — рендер markdown/LaTeX (`MarkdownContent`, демо-контент). Обводка карточки — тонкая индиго-рамка со скруглением, как на скрине.
  - Правая (~1fr): «Заметки для учителя» — заголовок + рендер markdown-заметок (без рамки, просто колонка).
- Над двумя колонками — строка-«чипсы» параметров: `Литература ⌄`, `6 параллель ⌄` (визуальные бейджи из сохранённых параметров).
- Нижняя плавающая панель по центру (по референсу): `Текст`, `Вопрос`, `ИИ-помощник ✦ 5` — декоративные пилюли-кнопки.

### Оценка

Панель оценки (`EvaluationPanel`) на этом макете отсутствует. Решение: оставлю её функционально, но переоформлю как **выезжающую панель** (кнопка «Оценить» в верхней панели рядом с «Выдать» → открывает `Sheet` справа с текущим содержимым, перекрашенным под новую палитру: сегменты «плохо/скорее плохо/скорее хорошо/хорошо», звёзды, комментарий, «Отправить» в Supabase).

Если хочешь оставить панель постоянно видимой слева — скажи, и оставлю трёхколоночный layout, но это отклонение от референса.

### Экран 3 — Модалка «Перегенерировать»

Добавлю модалку (`Dialog`), открываемую кнопкой в верхней панели плеера (например, иконка `...` → пункт «Перегенерировать», либо отдельная кнопка):
- Заголовок «Мотивирующее задание» + `✕`.
- Селект «Формат задания» (значение по умолчанию — из параметров).
- Тоггл «Добавить иллюстрацию».
- Textarea «Как нужно изменить задание» (placeholder «Повысить сложность, изменить формат работы, добавить примеры…»).
- Кнопки: `Отменить` (закрыть) и `Перегенерировать` (индиго; сейчас — просто закрывает модалку и показывает toast «Функция будет подключена к ИИ», т.к. бэк ещё не готов).
